# 건물 사진 / 폴라로이드 아카이브

사진 147장에 대해 작은 카드용 640px, 확대용 1440px WebP를 따로 만들었습니다.
파일명은 상세 주소 대신 임의 ID입니다. EXIF/GPS/XMP는 포함하지 않습니다.
사이트 카드에서는 thumbs/ 이미지만 불러오고, 사진을 확대할 때 해당 확대용 파일을 불러옵니다.
원본 고해상도 파일은 개인 컴퓨터에서 따로 보관하세요.

## 제목과 정보 수정
metadata.json에서 사진 파일명(예: photo-90c0017cdd68.webp)을 찾아 수정하세요.
title: 카드 제목 / location: 동·읍·면까지의 위치 / year: 연도
description: 뒷면 설명 / material: 재료 / credit: 촬영자
thumbnail은 해당 사진의 thumbs/ 경로를 유지하세요.
도로명·번지·상세 주소는 입력하지 마세요. 화면의 위치와 제목도 행정구역 수준으로 제한합니다.

## 새 사진 추가
이 폴더 바로 아래에 JPG/JPEG/PNG/WebP/AVIF를 업로드하면 자동 조회됩니다.
새 사진은 업로드 전에 웹용으로 줄이고, 파일명에는 상세 주소를 쓰지 마세요.
사진별 제목과 위치는 metadata.json에서 지정할 수 있습니다.
작은 카드 전용 이미지가 있다면 thumbs/에 넣고 metadata.json의 thumbnail에 그 경로를 입력하세요.
새로 올린 원본을 사이트가 자동으로 압축하지는 않습니다.

## 로딩
한 번에 최대 24장, 나머지는 정렬 모드의 페이지 넘김으로 봅니다.
사진 목록은 15분 캐시되며 Shift + '다른 사진'으로 즉시 갱신할 수 있습니다.
GitHub API 연결이 안 되면 photos.json의 배포된 목록을 사용합니다.
photos.json은 사진 파일명 배열이며, 새 파일 추가 시 같이 갱신하면 예비 목록에도 반영됩니다.

## 공개 이력
현재 배포 파일에서 상세 주소가 든 원본 파일명을 제거했습니다.
GitHub의 과거 커밋에는 이전 파일명과 원본이 남아 있습니다. 이 변경은 저장소 이력을 삭제하지 않습니다.
