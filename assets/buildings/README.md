# 건물 사진 업로드

이 폴더에 JPG / JPEG / PNG / WEBP / AVIF 사진을 직접 업로드하세요.
GitHub 화면에서 Add file → Upload files → Commit changes.
사진은 이 폴더 바로 아래에 넣어주세요 (하위 폴더 제외).

사이트: https://sogoose.github.io/hetero-front/landscapes.html

## 사진과 표시 제목

기본 제목은 파일명에서 확장자를 뺀 값입니다. 밑줄은 공백으로 표시됩니다.
예: 서울_종로구_주택.webp → 서울 종로구 주택

metadata.json에서 정확한 파일명을 키로 써 제목과 상세 정보를 입력할 수 있습니다.
입력하지 않은 값은 표시하지 않습니다. 정보는 사진 자체와 별도로 관리됩니다.
기존 metadata.json의 예시를 참고하고, JSON 쉼표와 큰따옴표를 유지하세요.
브라우저에서 수정하는 관리자 기능은 없습니다. GitHub에서 파일을 편집합니다.

## 권장 이미지

긴 변 1200–1600px, WebP/JPG, 장당 150–400KB 권장.
원본 고해상도는 따로 보관하고 웹용 사본을 업로드하세요.
사이트가 원본을 자동 압축하지는 않습니다. 큰 원본은 24장만 불러와도 느릴 수 있습니다.
한 번에 최대 24장만 로드하며 정렬 모드에서는 페이지를 넘겨 전체 사진을 봅니다.
흩어 보기에서는 최대 24장을 랜덤으로 선택합니다.

## 자동 반영

공개 GitHub Contents API로 폴더를 한 번 조회하고 목록을 15분간 브라우저에 캐시합니다.
새 사진은 배포 후 최대 15분 뒤 반영됩니다. '다른 사진' 버튼을 Shift와 함께 누르면 목록을 즉시 새로 조회합니다.
정보(metadata.json)는 페이지를 열 때마다 새로 읽습니다.
API 요청 제한/네트워크 오류 시 저장된 목록을 사용하며, 저장된 목록도 없으면 안내문과 기존 자료 미리보기를 표시합니다.
폴더에 사진이 없을 때만 기존 연구자료 6장이 예시로 표시됩니다.
공개 저장소이므로 업로드한 사진과 정보는 공개됩니다.
