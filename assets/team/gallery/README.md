# Atelier 作 — 소개 페이지 이미지 갤러리

GitHub에서 이 폴더에 사진을 업로드하면 `who-are-we.html`의 왼쪽 갤러리에 자동으로 표시됩니다.

- 지원 파일: JPG, JPEG, PNG, WEBP, AVIF, GIF, SVG
- 파일명을 `01-team.jpg`, `02-studio.jpg`처럼 지정하면 파일명 순서대로 정렬됩니다.
- 새 파일을 업로드한 뒤 사이트를 새로고침하면 갤러리에 나타납니다.
- 이미지 클릭 확대 기능은 없습니다.
- 파일 크기가 크면 웹용으로 줄인 뒤 올리는 것을 권장합니다.

아래의 파일은 폴더 유지 및 안내를 위한 것으로, 갤러리에는 표시되지 않습니다.
