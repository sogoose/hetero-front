# MATERIAL / Sticker Assets

이 폴더는 `materials.html`의 가로 스티커 아카이브에 들어갈 최종 누끼 이미지를 위한 공간입니다.

## 이미지 교체

- 준비된 누끼 이미지를 `sticker-01.webp`부터 `sticker-17.webp`까지 같은 이름으로 이 폴더에 올리면 자동으로 교체됩니다.
- PNG도 쓸 수 있지만, 현재 매니페스트는 WebP 이름을 사용합니다. PNG로 올린 경우 `stickers.json`의 `image` 경로 확장자도 바꾸면 됩니다.
- 새 이미지가 없을 때는 기존 `assets/archive/specimens.webp`의 임시 크롭 또는 기존 독립 이미지를 사용합니다.
- 이미지는 가급적 투명 배경, 충분한 해상도로 내보내 주세요. 추천: 세로 또는 가로 긴 변 1000~1600px, WebP 품질 80~88.
- 스티커 순서, 이름, 기울기, 배치는 `stickers.json`에서 관리합니다. 원본 아카이브 기록에는 영향을 주지 않습니다.
- 배포 사이트: https://sogoose.github.io/hetero-front/materials.html
- 업로드 위치: https://github.com/sogoose/hetero-front/upload/main/assets/materials

각 스티커의 일련번호는 임시 식별자이며 실물 재료나 준공연도를 뜻하지 않습니다.
