# INTERVIEWS / 편집 안내

이 페이지는 제공된 6쪽 PDF **「PART 3-1 인터뷰 전문 - 발췌, 편집(전시용 축약)_261101」**을 출처로 합니다. **전체 녹취록이 아니라 전시용 발췌·편집본**입니다.

- **인터뷰 내용:** `assets/interviews/interviews-data.json`
- **세로형 레이아웃:** `interviews-scroll.css`
- **스크롤·하단 이동 버튼:** `interviews-scroll.js`
- **페이지:** `interviews.html`

## 인터뷰 수정

기와(고령기와) → 주물(정우금속) → 벽돌(청화요업) 순서로, 한 페이지에서 **아래로 스크롤해 연속으로 읽습니다**.

중간의 주제별 소제목 없이 PDF의 발췌 텍스트를 질문과 답변 순서대로 표시합니다.
`interviews-data.json`에서 `material`, `company`, `person`, `place`, `date`, `illustration`, `turns`를 수정하면 됩니다.

```json
{"role":"Q","text":"질문 내용"}
```

```json
{"role":"A","text":"답변 내용"}
```

- **Q. 질문**은 연한 적갈색의 보통 두께
- **A. 답변**은 진한 회색의 볼드
- 긴 문장은 한 글자씩 세로로 끊기지 않도록 **너비가 제한된 한 개 본문 열**로 표시
- 큰 화면에서는 왼쪽에 회사 정보와 이미지, 오른쪽에 본문
- 작은 화면에서는 회사 정보 위 / 본문 아래
- 기존 MATERIALS와 같은 배경색, 고정 하단 내비게이션
- 하단 기와 / 주물 / 벽돌 버튼으로 각 인터뷰 시작점 이동
- 페이지는 **세로 스크롤**, 가로 스크롤 사용 안 함

이미지는 `illustration`을 변경하면 교체됩니다. 경로는 `interviews.html` 기준으로 입력하세요.

PDF 발췌와 달리 추가할 내용이 생기면 출처를 확인한 뒤 JSON의 해당 발화에 반영해 주세요.
