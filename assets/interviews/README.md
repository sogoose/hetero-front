# INTERVIEWS / 편집 안내

이 페이지는 제공된 6쪽 PDF **「PART 3-1 인터뷰 전문 - 발췌, 편집(전시용 축약)_261101」**을 출처로 합니다. **전체 녹취록이 아니라 전시용 발췌·편집본**입니다.

- **내용 수정:** `assets/interviews/interviews-data.json`
- **레이아웃 수정:** `interviews-scroll.css`
- **가로 배치·스크롤 동작:** `interviews-scroll.js`
- **페이지:** `interviews.html`

## 내용 바꾸기

`interviews-data.json`은 3개의 인터뷰로 분리돼 있습니다. 순서: 기와(고령기와) → 주물(정우금속) → 벽돌(청화요업).

인터뷰마다 `material`, `company`, `person`, `place`, `date`, `illustration`, `turns`를 수정할 수 있습니다.

질문과 답변은 `turns` 배열에서 순서대로 이어집니다.

```json
{
  "role": "Q",
  "text": "질문 텍스트"
}
```

```json
{
  "role": "A",
  "text": "답변 텍스트"
}
```

질문은 굵은 글씨, 답변은 일반 글씨로 처리합니다. 인터뷰 중간의 주제 소제목은 표시하지 않습니다. PDF에서 실제로 질문 없이 시작하는 답변도 그대로 유지했습니다.

## 이미지 교체

`illustration`은 각 인터뷰 제목 아래의 작은 이미지에 연결됩니다. 예:

`"illustration": "assets/archive/tiles-photo.webp"`

사용할 수 있는 형식은 PNG, WebP, SVG, JPEG입니다. 배경 없는 누끼 이미지가 더 잘 어울리며, 기존 이미지 파일은 변경하지 않습니다.

## 화면과 조판 규칙

- MATERIALS와 비슷하게 **페이지 높이 전체를 사용하고 아래로 스크롤하지 않습니다.**
- 마우스 휠/트랙패드/가로 스와이프 또는 하단 버튼으로 가로 이동합니다.
- 본문은 화면 높이에 맞춰 **다음 열로 자연스럽게 흘러가는 다단 조판**입니다. 브라우저 폭에 따라 열 개수가 달라져도 텍스트가 잘리지 않습니다.
- 하단의 기와/주물/벽돌 선택을 누르면 각 인터뷰 시작 지점으로 이동합니다.
- 모바일 역시 한 화면 높이 안에서 가로로 읽습니다.
- 실제 원문과 다른 사실을 보완하거나 미확인 문구를 임의로 추가하지 마세요.
