# RESEARCH 자료 교체 안내

이 페이지는 세 장의 가로 도판으로 구성됩니다. 세로로 스크롤하지 않습니다.

- 실제 내용과 이미지 경로: assets/research/research-data.json
- 페이지 구조: research.html
- 화면 디자인: research-page.css
- 지도 전환과 도상 확대: research-page.js

**대부분의 수정은 research-data.json 한 파일에서 끝납니다.** HTML과 JS는 수정하지 않아도 됩니다.

## 업데이트: 실제 업로드한 지도 파일 (1991 / 2026)

실제 업로드된 지도에는 공통 지도 `assets/research/map.png`와 각 재료별 투명 분포 레이어가 있습니다.
이제 `mapBase` 및 `maps[].images` 경로에서 원본 파일을 직접 연결합니다.

| 재료 | 1991 | 2026 |
| --- | --- | --- |
| 벽돌 | `brick_1991xxxhdpi.png` | `brick_2026xxxhdpi.png` |
| 기와 | `roof_1991xxxhdpi.png` | `roof_2026xxxhdpi.png` |
| 주물 | 없음 (`null`) | `casting_2026xxxhdpi.png` |

첫 연구 도판은 연도(1991 / 2026)와 재료(종합 / 벽돌 / 기와 / 주물)를 따로 선택합니다.
**1991년에는 주물 지도가 없으므로 주물 선택이 비활성화됩니다.** 종합 지도는 있는 레이어만 합성합니다.
공통 베이스맵과 각 오버레이는 동일 좌표·캔버스 크기의 투명 PNG로 맞춰 업로드하세요.

**나중에 자료를 교체할 때** `research-data.json`의 `mapBase` 또는 `maps` 배열의 `images["1991"]`, `images["2026"]` 필드만 수정하세요.
새 주물 1991 파일을 추가하면 `null` 대신 해당 경로를 넣기만 하면 됩니다.

## 01 / DISTRIBUTION — 지도 4장

실제 지도가 이미 연결돼 있습니다. `combined`는 선택한 연도의 자료가 존재하는 레이어를 합쳐 보여줍니다. 각 `maps[].images`에서 연도별 경로를 교체하고, 추가 연도가 필요하면 `mapYears`에 등록하세요. `null`은 지도 미등록이라는 뜻입니다.

## 02 / PRODUCTION — 생산과 유통

JSON의 production.stages 배열에서 각 단계의 image를 교체하세요.

예: "image": "assets/research/process/merchant.webp"

원형 / 공장 / 건재상 / 시공자 / 혼종 주택의 다섯 단계를 기본으로 표시합니다.
label은 단계 이름, sub는 작은 부제목, description은 클릭해 확대했을 때 보이는 설명입니다.
image가 null이면 검은 선형 기본 도상이 표시됩니다. 현재 일부 단계는 기존 assets/archive 이미지로 시연합니다.
원래 전시 도면을 개별 부재 PNG/WebP 투명 배경으로 분리하면 가장 잘 어울립니다.

## 03 / TESTIMONY — 제작자 인터뷰

JSON의 testimonies.items 배열에서 이미지, 질문, 발언을 수정하세요.

- material: 벽돌 / 기와 / 주물
- question: 질문
- quote: 인용문
- speaker: 인터뷰이 / 출처
- image: 이미지 주소
- detail: 이미지를 클릭하면 열리는 설명
- href: 자세한 인터뷰 페이지 주소 (기본 interviews.html)

데스크톱에서는 세 열, 모바일에서는 탭으로 하나씩 보입니다.

## 2026년 벽돌공장 — DXF 업체명·위치 연결 완료

업로드한 **\`벽돌 2026(1).dxf\`**에서 공장 17곳의 번호·업체명·주소·위치 기호를 읽어, \`assets/research/brick_2026xxxhdpi.png\`에 연결했습니다.

- **지도 접근:** RESEARCH 01 / 지도 → 벽돌 → 2026. 파란 핀이나 기존 기호를 누르면 해당 업체명·주소·DXF 번호·원본 출처가 표시됩니다.
- **등록 수:** 17곳. 01–17번 모두 위치 기호가 있으며 미배치 항목이 없습니다. 가까운 업체는 목록형 핀으로 묶입니다.
- **좌표 검증:** 2382×3368 지도 PNG와 DXF 위치 기호 중 10개 기준점을 비교해 평균제곱근 오차 약 0.44픽셀, 최대 오차 약 0.74픽셀로 정렬했습니다. 캔버스 상대좌표는 \`factory-points.json\`의 \`x\`, \`y\`입니다.
- **원본 정확도 주의:** DXF에는 \`exact\`, \`exact-ish\`, \`approx\`가 혼재하고, 한반도 윤곽은 도식적이라고 명시돼 있습니다. 웹 지도에서 위치 기호가 일치하는 것은 **원본 DXF의 실제 지리 좌표가 모두 정확하다**는 의미가 아닙니다. 업체 상세 \`note\`에 원본 좌표 정확도 표시를 남겼습니다.
- **명칭 주의:** 17번은 DXF에 \`<청화요업>\`으로 기재돼 있어 그 표기를 유지했습니다. 원본 표기가 확정되지 않았다면 최종 교정 단계에서 확인하세요.
- **기존 데이터 보존:** 1991년 벽돌 58곳, 2026년 주물 27곳과 미배치 기록은 변경하지 않았습니다.

## 1991년 벽돌공장 — DXF 업체명·위치 연결 완료

첨부 원본 `벽돌 1991.dxf`의 **1991년 벽돌 관련 협동조합 회원사 59곳**을 확인했습니다. 이 가운데 원본 DXF 번호와 원형 위치 기호가 대응되는 **58곳**을 지도에 연결했습니다.

- **표시:** RESEARCH 첫 도판에서 **벽돌 → 1991년**을 고른 뒤 파란 원형 기호(또는 등록 핀)를 클릭하면 업체명·당시 자료의 지역 표기·번호·출처가 나옵니다
- **밀집 지역:** 가까운 업체 위치는 숫자 클러스터로 나타나며, 클릭하면 업체 목록을 펼칩니다
- **미배치:** `14 선도산업(주)`(하남 초이동 일대)은 DXF 번호에 대응되는 위치 원형이 확인되지 않아 임의로 지정하지 않고 `factory-points.json`의 `unplaced`에 보관했습니다
- **원본:** `assets/research/brick_1991xxxhdpi.png` (2382 × 3368), `벽돌 1991.dxf`
- **출처:** 중소기업협동조합중앙회, 『中小企業協同組合 組合員業體名簿』, 1991 (DXF 출처 표기)
- **좌표 검증:** DXF 좌표를 웹 지도와 동일한 기준으로 환산했고, 겹치지 않는 원형 기호 38개를 PNG와 대조해 평균 약 0.57픽셀 차이를 확인했습니다

**주의:** 이 자료는 1991년 전국 벽돌공장 전수조사가 아니라 **협동조합 회원사 기록**입니다. DXF에는 현재 행정구역의 시·군·읍·면 중심을 기준으로 근사한 위치라고 명시돼 있습니다. 따라서 개별 공장 필지의 정확한 주소나 좌표로 해석해서는 안 됩니다. `득선영(?)`처럼 원본에 불확실성 기호가 붙은 명칭도 그대로 옮겼습니다.

기존 **2026년 주물 27곳**도 동일한 JSON에 유지되며, 각각 다른 재료·연도 필터에서 표시됩니다.

## 2026년 주물공장 — DXF 번호·업체명 연결 완료

첨부 원본 `주물(1).dxf`의 업체 목록 28곳을 확인하고, 번호가 표시된 원형 기호 **27개(01–12, 14–28)**를 지도에 연결했습니다.

- 공개 데이터: `assets/research/factory-points.json`의 `points` (27곳)
- 지도 레이어: `assets/research/casting_2026xxxhdpi.png`
- 출처: 한국산업단지공단 전국등록공장현황 2025.12 (DXF에 표시된 출처)
- 원본 PNG의 색상 기호와 DXF 원형 기호를 비교해 좌표를 변환했으며, 등록된 핀은 **주물/2026년**에서만 표시됩니다.
- 수도권 등 가까운 점은 작은 숫자 핀으로 묶입니다. 숫자를 누르면 업체 목록이 나오고, 업체명을 누르면 주소·원자료 번호·출처가 표시됩니다.
- `13 해성DBR`은 업체명과 주소만 DXF에 있고 지도 기호 번호 13이 없어 **임의의 위치를 지정하지 않았습니다.** `factory-points.json`의 `unplaced`에 보관했습니다. 원본에서 위치가 확인되면 수동 등록 후 여기를 업데이트해 주세요.
- 공개 지도에 없던 새로운 업체를 추가할 때만 **업체 위치 입력**과 **JSON 내보내기**를 사용하면 됩니다. 다른 자료의 기존 위치에 덮어쓰지 마세요.

**기술적 좌표:** `factory-points.json`의 `x`/`y`는 `casting_2026xxxhdpi.png` 전체 캔버스(2382×3368)의 0~1 상대좌표입니다. `coordinateCalibration`에는 DXF-래스터 기준점 비교 정보가 있습니다. 새로운 이미지로 갈아끼울 때는 **재료 레이어의 아트보드 크기와 정렬**을 먼저 확인해야 합니다.


## 업체별 위치·이름 붙이기 (신규)

**파일:** `assets/research/factory-points.json`

지도 PNG에 찍힌 점만으로는 어느 공장인지 자동으로 알 수 없습니다. 현재 1991년 벽돌공장 58곳과 2026년 주물공장 27곳이 공개되어 있습니다. 확인할 수 없는 업체의 위치는 추측해서 넣지 않았습니다.

1. [RESEARCH 페이지](../../research.html)의 지도에서 **벽돌 / 주물 / 기와**를 선택합니다. 각 재료마다 **1991 / 2026**년을 선택할 수 있으며, 1991년 주물 지도는 아직 없으므로 해당 재료는 2026년으로 자동 전환됩니다.
2. 오른쪽 아래 **업체 위치 입력**을 눌러 입력 모드로 전환합니다.
3. 지도 PNG의 실제 기호 중심을 눌러 그곳의 **업체명 / 지역 / 자료 출처 / 메모**를 적고 저장합니다. 기존에 저장한 핀을 클릭해 정보를 수정하거나 삭제할 수도 있습니다.
4. **입력 완료**를 누르면 일반 보기로 돌아갑니다. 이제 등록된 핀을 누르면 이름과 설명이 오른쪽에 표시됩니다.
5. 입력 모드에서 **JSON 내보내기**를 눌러 `factory-points.json`을 내려받습니다. 이 파일을 GitHub의 `assets/research/factory-points.json`에 교체 업로드하면 모두에게 공개됩니다.

**중요:** 브라우저에서 입력한 내용은 우선 해당 기기의 `localStorage`에 임시 저장됩니다. GitHub에 자동 업로드되지는 않습니다. 다른 기기나 방문자에게 보이게 하려면 JSON 파일을 교체해야 합니다.

좌표는 지도 원본 PNG 전체의 가로/세로 비율(`0`–`1`)입니다. 이미지의 표시 크기가 달라져도 핀은 같은 상대 위치에 남습니다. 베이스맵과 공장 위치 이미지를 교체할 때는 **모든 이미지의 캔버스 비율과 정렬을 일치**시켜야 합니다.

예시 스키마(아래는 *서식만 보여주는 예시*이며 실제 조사자료가 아닙니다):

```json
{
  "version": 1,
  "coordinateSystem": "original-map-image-normalized",
  "points": [
    {
      "id": "factory-example",
      "name": "실제 업체명을 입력하세요",
      "material": "brick",
      "year": 1991,
      "x": 0.52,
      "y": 0.43,
      "region": "조사 지역",
      "note": "확인한 내용",
      "source": "조사표 또는 인터뷰 출처"
    }
  ]
}
```

실제 공개 JSON에는 검증된 업체만 넣어주세요.
