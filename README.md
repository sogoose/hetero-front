# HETERO FRONT / 혼종의 정면

대한민국 산업화 과도기 건축재료의 기록과 해석.

아틀리에 作 — 손정호 · 박소현 · 이석주 · 이철원

## Pages

- Home: `index.html`
- Materials: `materials.html`
- Research: `research.html`
- Interview archive: `interviews.html`
- Exhibition: `exhibition.html`

Static HTML, CSS, and JavaScript. No build step required. Enable GitHub Pages from the `main` branch, `/ (root)`.

The materials reader uses a Supabase publishable key and read-only public access policies. No secret or service-role key is included.

## 풍경 / 폴라로이드 아카이브

`landscapes.html` — 흩어 보기, 정렬 갤러리, 상세 정보.
사진은 `assets/buildings/`에 업로드하고 표시 정보는 같은 폴더의 `metadata.json`에서 편집하세요.
자세한 업로드 안내: [assets/buildings/README.md](assets/buildings/README.md).
